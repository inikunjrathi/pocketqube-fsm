# Manuscript

`paper.tex` is the `elsarticle` source of the paper. It covers the schema and
engine, Configs A, B and C, the test suite and TLC model checking, the
POQUITO-based simulation, the policy comparison, the sensitivity, worst-case
and second-station runs, ground-command authentication, and the C port on
Renode.

| File | Purpose |
|---|---|
| `paper.tex` | manuscript |
| `refs.bib` | 41 references, each checked against Crossref, arXiv or the issuing body's document on 2026-10-06 |
| `transitions.tex` | appendix tables, generated from `config/*.yaml` by `make_transition_tables.py` |
| `timings.tex` | re-run macros, generated by `fill_rerun_macros.py` from the policy timings and `cport.txt` |
| `check_cport_evidence.py` | recounts the archived Renode replay logs and compares them with a fresh Python capture; its output is `cport.txt` |

## Rebuild the numbers

From the repository root:

```
pip install -r requirements.txt                            # sgp4 pinned to 2.27
.venv/bin/python -m pytest -q --junitxml=build/junit.xml   # 1,213 tests
.venv/bin/python tools/generate_baseline_results.py
.venv/bin/python tools/generate_policy_comparison.py       # slowest step (~20 min on 30 cores); also appends the same-input timing section
.venv/bin/python tools/generate_sensitivity_analysis.py
.venv/bin/python tools/generate_ground_station_analysis.py
.venv/bin/python tools/generate_worst_case_scenarios.py
bash tools/run_model_check.sh                              # TLC, needs java
.venv/bin/python mcu/host_bridge/replay_baseline.py --west <west> --zephyr-sdk-dir <sdk-0.17.4> --zephyr-base <zephyr-4.2.2>   # full Renode replay, ~1 h
```

The host build of the C auth tests defines `MBEDTLS_DECLARE_PRIVATE_IDENTIFIERS`,
which mbedTLS 4.x needs before it declares `mbedtls_md_hmac`.

The policy-timing table (`tab:complexity`) and the re-run table are written
into `paper.tex` by hand from `docs/policy-complexity-analysis.md` ("Same-input
benchmark" section) and the generator outputs. `TestCount` and
`ReplayOutcome` at the top of `paper.tex` hold the two numbers most likely to
change.

## Build the PDF

```
cd report/elsevier
../../.venv/bin/python make_transition_tables.py
latexmk -pdf paper.tex
```

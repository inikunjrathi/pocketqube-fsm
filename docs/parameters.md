# Parameters — Config A

Per section 4 of the plan, every numeric guard value not explicitly given by
the use-case document is a configuration parameter with a cited or
explicitly-assumed justification. This table is itself a graded artifact:
every `Assumed` row must carry an actual justification sentence, not a bare
number. No ICD exists yet (decision record 0001) — all Config-A-specific
values below are proceeding on assumption pending real mission data.

Cross-reference: parameters are consumed by transitions (`T-xx`,
`../state-machine/config-a-transitions.md`) and cited by requirements
(`R-xx`, `../requirements/requirements-config-a.md`).
